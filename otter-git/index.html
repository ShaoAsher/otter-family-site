      小獭 AI

      动手之前，先确认。

      看状态、拉取、推送这些短指令不配模型也能用；配上模型后，写提交说明、起草 PR、把「提交并推送」拆成几步，都可以交给它。

      • 每一步都摆出来多步任务拆成步骤卡：做完、进行中、待执行一眼分清。
      • 写操作先出确认卡列出涉及的文件、目标分支和风险等级。强制推送、硬重置、丢弃改动每次单独确认。
      • 会话按仓库分开每个仓库有自己的对话与习惯；仓库里有 AGENTS.md 时也会读。
      • 模型由你接入填接口地址、API Key 和模型名即可，用量随时可查。

      常见问题

      你可能想问的

      要花钱吗？

      不用。没有内购、订阅或专业版。模型由你自己接入，费用与服务商直接结算。

      小獭会擅自改仓库吗？

      出厂是「默认」档：日常操作直接执行，拉取、推送等会先确认；不可撤销的操作每次单独确认。冲突没解完的提交，任何一档都会拦下。

      代码会被上传吗？

      仓库读写都在本机，用的是你安装的 git。配置模型并对话时，相关内容会发到你填写的接口。

      支持哪些系统？

      macOS 12+（Apple Silicon）与 Windows 10 / 11（x64 预览版）。Intel Mac 暂不提供安装包。本机需已安装 git。

      为什么叫水獭？

      水獭睡觉时会牵着同伴的手，避免彼此走散。分支一多也容易走散，总得有谁帮你盯着。
